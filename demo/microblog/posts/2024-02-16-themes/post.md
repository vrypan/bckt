Themes bundle templates, static assets, and starter pages together.

`bckt themes install <name>` installs one from the bundled themes or
from a `.zip` archive; `bckt themes use <name>` applies it to the
current project.

This demo was started with:

```
bckt init --theme microx --demo microblog
```

The other bundled themes — `micro`, `bckt3`, `modern`, `plain`,
`rntz` — are worth trying. Use 

```
bckt themes install modern
bckt themes use modern
```

to try the modern theme.
